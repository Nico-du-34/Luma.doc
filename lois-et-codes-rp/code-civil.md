# 🏛️ Code civil

Le code civil règle les relations entre citoyens hors infractions pénales.

### Cadre

Cette page présente les règles applicables dans le cadre RP. Elles servent de base aux scènes, aux contrôles et aux décisions judiciaires.

### Règles principales

* contrats et engagements
* propriété et dettes
* litiges privés
* réparation des préjudices

### Bonnes pratiques

* rester cohérent avec la scène en cours
* expliquer les décisions importantes aux personnes concernées
* garder une trace lorsqu’un litige est possible
* faire appel au staff seulement si le cadre RP ne suffit plus

### À retenir

Il sert surtout à résoudre les conflits sans passer par une logique pénale.
