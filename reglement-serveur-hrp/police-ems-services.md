# 04 - Police, EMS et services publics

## Police - principes

| Regle | Detail |
| --- | --- |
| Proportionnalite | Adapter la reponse au danger reel |
| Negociation avant assaut | Obligatoire si otage sauf danger immediat |
| Pas de win police | Le but est une scene, pas une victoire automatique |
| Respect des droits | Annoncer les faits, fouille justifiee, avocat si disponible |
| Usage force progressif | Parole, taser, arme non letale, arme letale en dernier |

## Usage arme de service

Il est interdit de tirer avec son arme de service sauf exception justifiee.

| Situation | Tir autorise ? |
| --- | --- |
| Suspect fuit sans arme | Non |
| Suspect insulte/provoque | Non |
| Vehicule fuit sans danger immediat | Non, privilégier poursuite |
| Suspect pointe une arme | Oui |
| Suspect tire | Oui |
| Suspect fonce volontairement sur civils/agents | Oui si danger immediat |
| Otage menace d'execution | Oui si tir propre possible |
| Animal/PNJ bug dangereux | Selon situation |

Un tir non justifie peut entrainer sanction interne, retrait arme, suspension police ou sanction administrative selon `07_reports_sanctions.md`.

## Nombre d'agents sur scene

| Scene | Reponse conseillee |
| --- | --- |
| Controle routier | 1 a 2 agents |
| Refus d'obtemperer simple | 2 a 4 agents |
| Braquage 1 suspect sans otage | 2 a 3 agents |
| Braquage 1 suspect avec otage | 3 a 4 agents |
| Braquage groupe | Adapter au nombre de suspects |
| Fusillade active | Renforts libres selon danger |

La police ne doit pas ecraser une petite scene avec un surnombre absurde.

## Poursuites

| Regle | Detail |
| --- | --- |
| PIT | Autorise si vitesse et zone raisonnables |
| PIT en ville dense | Interdit sauf danger majeur |
| Tir pneus | Autorise seulement si danger eleve |
| Barrage | Doit laisser une chance de reaction |
| Helicoptere | Reserve scenes importantes |
| Ram volontaire abusif | Interdit |

## EMS

| Regle | Detail |
| --- | --- |
| EMS neutre | Ne doit pas etre pris pour cible |
| EMS ne fait pas police | Ne donne pas d'information tactique abusive |
| EMS joue les blessures | Peut refuser soin instant si scene dangereuse |
| Kidnapping EMS | Interdit sauf event annonce ou dossier illegal majeur valide avant la scene |
| Vol vehicule EMS | Interdit sauf scene majeure validee |

## Corruption police/EMS

La corruption de service public doit etre rare, encadree et validee par le responsable de faction et l'administration avant d'etre jouee. Un agent ne peut pas devenir criminel lourd sans autorisation ecrite.

## Fouilles et menottage

| Action | Regle |
| --- | --- |
| Fouille pendant controle simple | Interdite sans suspicion precise |
| Fouille apres arrestation | Autorisee |
| Menottage abusif | Interdit |
| Laisser un suspect menotte sans scene | Interdit |
| Confisquer telephone/radio | Autorise si justifie, doit etre annonce |
| Prendre tout l'inventaire | Interdit sauf objets lies aux faits |

## Unites speciales

| Usage | Regle |
| --- | --- |
| Intervention lourde | Reservee armes lourdes, otages, fusillade, crime majeur |
| Sniper | Uniquement scene otage/fusillade majeure |
| Helicoptere | Recherche, poursuite importante, braquage majeur |
| Blindes | Event annonce ou menace exceptionnelle |

## Procedure SASP d interpellation

Le SASP doit appliquer une procedure lisible pour eviter les fouilles abusives et les scenes bloquees.

| Etape | Obligatoire | Detail |
| --- | --- | --- |
| Motif du controle | Oui sauf urgence | L'agent annonce la raison du controle si la situation le permet. |
| Sommations claires | Oui | Les sommations doivent etre audibles et comprehensibles. |
| Usage progressif de la force | Oui | La force doit correspondre au danger reel. |
| Fouille justifiee | Oui | Fuite, arme visible, suspicion credible, mandat ou scene illegale. |
| Lecture des faits reproches | Oui | Le suspect doit comprendre pourquoi il est interpelle. |
| Avocat | Si disponible | Obligatoire pour dossier lourd si le DOJ est actif. |
| Rapport | Oui pour saisie lourde | Arme, vehicule, perquisition, gros trafic, peine lourde. |

Un agent SASP ne peut pas fouiller, saisir ou emprisonner sans raison RP claire.

## Usage de la force SASP

| Niveau | Autorise quand |
| --- | --- |
| Dialogue / controle | Infraction mineure, renseignement, prevention |
| Menottage | Fuite, danger, refus d'obtemperer, suspicion serieuse |
| Taser | Individu dangereux non arme a distance raisonnable |
| Tir pneus | Poursuite prolongee, danger public, sommations effectuees |
| Arme a feu | Menace directe, arme sortie, tir recu, vehicule utilise comme arme |

Le tir lethale ne doit jamais etre le premier reflexe si la situation peut etre geree autrement.

## Regles SAMS

| Situation | Regle |
| --- | --- |
| Intervention medicale | Prioritaire sauf danger direct encore actif. |
| Prise d'otage SAMS | Tres encadree, raison RP forte obligatoire. |
| Menace sur SAMS | Interdite sans scene majeure et justification solide. |
| Retour combat apres soin | Interdit de repartir immediatement au combat apres reanimation. |

Le SAMS n'est pas un outil pour reset une scene. Les blessures et consequences doivent etre jouees.
