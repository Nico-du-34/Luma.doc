# Procédure pénale

Cette page détaille le thème suivant: procédure pénale. Elle complète le code de procédure pénale.

## Étapes clés

* contrôle ou constat initial
* identification du suspect
* fouille si un motif légal existe
* saisie et rapport des preuves
* garde à vue si nécessaire
* décision: amende, libération, mandat ou audience

## À retenir

* rester proportionné
* noter les décisions importantes
* conserver les preuves utiles
* prévenir la justice pour les mesures lourdes
