# Code de procédure pénale

Le code de procédure pénale encadre la manière d’agir. Il protège la validité des actes.

Une bonne décision prise avec une mauvaise procédure peut être contestée.

### Principes de base

* toute mesure doit avoir un fondement clair
* toute contrainte doit rester proportionnée
* les droits du suspect doivent être respectés
* chaque étape importante doit pouvoir être justifiée

### Ce que la procédure encadre

* les contrôles
* les fouilles
* les interpellations
* les auditions
* les perquisitions
* les saisies
* la garde à vue
* le renvoi devant la justice

### Traçabilité

Toute intervention importante doit laisser une trace exploitable.

Exemples :

* rapport d’intervention
* motif du contrôle
* objet d’une saisie
* base d’un mandat

### Nullités et contestations

Une procédure peut être fragilisée si :

* le motif est absent
* les droits ne sont pas notifiés
* la mesure dépasse son cadre
* la preuve a été obtenue de manière irrégulière

Ces situations peuvent créer un vice de procédure. Consulte aussi [Justice RP](https://app.gitbook.com/s/XuNHWBdUeOFtjCuzDNyG/justice-rp).

### Règle pratique

Commence toujours par la mesure la moins intrusive. Monte en contrainte seulement si la scène le justifie.
