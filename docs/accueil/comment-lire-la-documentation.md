# ❓ Comment lire la documentation

Lis toujours du **général vers le spécifique**.

## Deux univers

La documentation sépare clairement :

| Univers            | À quoi ça sert                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------ |
| **Règlement**      | Comment jouer sur le serveur : fair-play, HRP, meta, fear, illégal, entreprises, services. |
| **Lois & justice** | Ce qui s’applique _dans_ le RP : constitution, codes, barèmes d’amendes, procédures.       |

Le règlement fixe le cadre hors-jeu et les règles de jeu. Les lois fixent les peines, qualifications et procédures jouables en scène.

## Ordre de lecture

1. **Accueil** — orientation et ton du serveur.
2. **Règlement** — principes, règles générales, puis pages liées à ton activité.
3. **Lois & justice** — textes fondamentaux, codes, barèmes, justice (si tu joues une scène judiciaire ou une sanction).
4. **Section métier** — SASP, SAMS, entreprises, illégal.

Si deux textes semblent se contredire, applique la [Hiérarchie des documents](hierarchie-des-documents.md).

Si une situation n’est pas couverte : privilégie le fair-play, puis ouvre un report si nécessaire.
