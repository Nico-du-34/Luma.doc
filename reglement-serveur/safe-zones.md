# 🛡️ Safe zones

Les safe zones protègent les interactions sensibles.

Dans une safe zone, évite toute action qui force une scène hostile.

Sont interdits :

* les agressions
* les enlèvements
* les braquages
* les intimidations forcées
* le blocage volontaire

N’utilise pas une safe zone comme refuge abusif. N’y bait pas une scène non plus.

La liste exacte des safe zones est fixée par le serveur. Une exception peut exister lors d’un event staff.
