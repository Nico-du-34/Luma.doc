# 06 - Entreprises et jobs

## Entreprises

| Regle | Detail |
| --- | --- |
| Prix coherents | Respecter l'economie serveur |
| Factures justifiees | Pas de facture abusive ou invisible |
| Patron responsable | Le patron repond des abus de son entreprise |
| Stock RP | Les ventes doivent correspondre a un stock ou service |
| Pas d'entreprise AFK | Interdit de generer argent sans interaction |
| Comptabilite propre | Les responsables doivent pouvoir justifier les gros retraits |

## Factures

| Situation | Regle |
| --- | --- |
| Facture mecanique | Doit correspondre au service |
| Facture EMS | Doit correspondre aux soins/intervention |
| Facture police | Voir code penal |
| Refus de payer | Scene RP ou dossier justice |
| Facture punitive abusive | Interdite |

## Jobs whitelist

| Regle | Detail |
| --- | --- |
| Respect hierarchy | Suivre reglement interne |
| Pas de give abusif | Items, argent, vehicules interdits hors cadre |
| Pas de double casquette abusive | Eviter conflit police/gang/business |
| Confidentialite | Infos internes non partagees sans raison RP |
| Service public prioritaire | Police/EMS doivent privilegier scenes utiles |

## Patron et employes

| Regle | Detail |
| --- | --- |
| Licenciement | Doit avoir raison RP ou gestion entreprise |
| Harcelement patron/employe | Interdit HRP |
| Salaire | Doit rester coherent economie |
| Coffre entreprise | Pas d'utilisation personnelle abusive |
| Argent societe | Retrait justifie uniquement |

## Businesses illegaux caches

Une entreprise peut servir de couverture seulement avec validation ecrite du responsable illegal et de l'administration avant utilisation. Sans validation, utiliser une societe legale pour blanchir, stocker armes/drogues ou organiser crimes est sanctionnable.

## Prix et economie

| Regle | Detail |
| --- | --- |
| Respect economie | Les prix doivent rester proches de `ECONOMIE_SERVEUR.md` |
| Dumping abusif | Vendre a perte pour casser un concurrent est interdit |
| Monopole force | Interdit sans scene economique valide |
| Fausses promotions | Interdit si objectif arnaque HRP |
| Cadeaux massifs | Interdit si cela contourne l'economie |
