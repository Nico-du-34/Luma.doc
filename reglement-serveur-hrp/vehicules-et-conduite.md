# 05 - Vehicules et conduite

## Vol de vehicule

| Situation | Regle |
| --- | --- |
| Vehicule en safe zone | Vol interdit |
| Vehicule proche hopital/commissariat/garage | Vol interdit sauf scene deja commencee |
| Vehicule civil en ville | Autorise avec scene credible |
| Vehicule police/EMS | Interdit sauf scene majeure |
| Vehicule entreprise | Autorise uniquement avec raison RP forte |
| Vehicule admin/event annonce | Interdit |

Il est interdit de voler un vehicule uniquement parce qu'il est ouvert si le lieu est safe ou si cela casse une scene.

## Conduite RP

| Regle | Detail |
| --- | --- |
| Conduite realiste | Adapter vitesse et conduite au contexte |
| Accident violent | Jouer consequences |
| Vehicule non offroad | Eviter montagnes/champs extremes |
| Sauts abusifs | Interdits en scene serieuse |
| Retour garage pendant poursuite | Interdit |
| Reparer instant en poursuite | Interdit |

## Courses

| Regle | Detail |
| --- | --- |
| Courses autorisees | Si organisees et hors safe zone |
| Courses en ville dense | Risque police et sanctions |
| Percuter civils volontairement | Interdit sauf scene criminelle majeure |
| Voiture supercar debutant | Possible seulement si economie permet, pas via give abusif |

## Vehicules import / rares

| Regle | Detail |
| --- | --- |
| Vehicule militaire | Whitelist ou event annonce |
| Vehicule arme | Interdit civil sauf event |
| Avions/helicos | Usage coherent, pas de troll |
| Spawn abusif | Interdit |
| Vente HRP de vehicules | Interdite |

## Parking et abandon

| Regle | Detail |
| --- | --- |
| Bloquer entree/sortie | Interdit |
| Abandon route principale | Fourriere possible |
| Garage camping | Interdit |
| Stocker vehicule pour eviter saisie | Sanctionnable |

## Poursuite et fair-play vehicule

| Action | Regle |
| --- | --- |
| Changer de vehicule en poursuite | Autorise si scene credible, pas via garage |
| Plonger volontairement dans l'eau | Interdit sauf vehicule adapte |
| Monter montagne en sportive | Interdit si non credible |
| Utiliser des tremplins urbains | Interdit en scene serieuse |
| Desync volontaire / lag switch | Ban |
| Bloquer un vehicule avec menu/garage | Interdit |
