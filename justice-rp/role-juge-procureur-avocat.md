# Rôle juge / procureur / avocat

Cette page détaille le thème suivant: rôle juge / procureur / avocat. Elle complète le code de procédure pénale.

## Étapes clés

* le juge tranche, contrôle et motive les décisions
* le procureur qualifie les faits et porte l’accusation
* l’avocat conseille, défend et relève les irrégularités
* chaque rôle doit favoriser une procédure claire

## À retenir

* rester proportionné
* noter les décisions importantes
* conserver les preuves utiles
* prévenir la justice pour les mesures lourdes
