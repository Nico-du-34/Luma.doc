# Vices de procédure

Cette page détaille le thème suivant: vices de procédure. Elle complète le code de procédure pénale.

## Étapes clés

* absence de motif clair
* droits essentiels non notifiés
* fouille sans lien avec les faits
* mandat trop vague
* preuve non tracée ou rapport absent

## À retenir

* rester proportionné
* noter les décisions importantes
* conserver les preuves utiles
* prévenir la justice pour les mesures lourdes
