# ❓ Comment lire la documentation

Lis toujours du général vers le spécifique.

Commence par l’accueil. Passe ensuite au règlement HRP. Lis enfin les règles liées à ton activité.

Utilise cet ordre :

1. **Accueil**
2. **Règlement serveur HRP**
3. **Textes fondamentaux RP**
4. **Lois et codes RP**
5. **Section métier ou activité**

Si deux textes semblent se contredire, consulte [Hiérarchie des documents](hierarchie-des-documents.md).

Si une situation n’est pas couverte, privilégie le fair-play. Puis ouvre un report si nécessaire.
