# 09 - Cas explicites d'intervention administrative

## Principe

Une intervention administrative pendant une scene est interdite par defaut. Les joueurs doivent finir la scene puis faire un report.

L'intervention en direct est autorisee uniquement dans les cas ci-dessous.

## Cas autorises

| Cas | Intervention autorisee |
| --- | --- |
| Cheat evident | Stop scene, freeze/kick/ban, sauvegarde preuves |
| Exploit argent/items en cours | Stop action, saisie logs, rollback possible |
| Duplication en cours | Stop action immediat |
| Doxx, menace reelle, propos haineux graves | Stop immediat, sanction lourde |
| Crash serveur imminent ou bug critique global | Pause ou annulation scene |
| Joueur bloque techniquement | Deblocage uniquement, sans avantage RP |
| Vehicule/objet bug qui detruit une scene | Suppression ou replacement technique |
| Freekill massif hors scene | Stop scene pour proteger les joueurs |
| Event annonce | Application des regles annoncees avant event |
| Litige impliquant un admin en RP | Un autre admin non implique traite apres scene |

## Cas non autorises en direct

| Cas | Regle |
| --- | --- |
| Desaccord sur Fear RP | Report apres scene |
| Desaccord sur conduite police | Report apres scene |
| Contestation amende/prison | Avocat/DOJ ou report apres scene |
| Suspicion metagaming sans preuve directe | Report apres scene |
| "Il m'a mal parle IC" | Code penal ou scene RP |
| Perte d'objet sans preuve | Ticket apres scene |

## Intervention technique

Une intervention technique doit etre minimale:

| Regle | Detail |
| --- | --- |
| Pas d'avantage RP | Ne pas donner position, armes, soin ou fuite |
| Annonce claire | Dire que l'action est administrative |
| Retour scene | Reprendre la scene si possible |
| Trace | Garder logs, clip ou note |

## Apres scene

Les sanctions et remboursements sont traites apres scene, avec preuves. Une scene terminee peut etre corrigee par sanction administrative, remboursement ou wipe partiel si un abus est prouve.
